# HelloYB.my

<img width="1920" height="726" alt="helloyb.my banner" src="https://github.com/user-attachments/assets/affc9a6a-f599-4688-abe9-1b04592a7daf" />

**HelloYB.my** is a simple, fast, and data-focused web application built to help voters in Sabah access clear information ahead of the 2025 state elections.  
This election cycle features **596 candidates** representing **24 parties** — the highest in Sabah’s history — which makes finding accurate, structured information more important than ever.

HelloYB.my brings key constituency and candidate data into one easy-to-navigate interface.

---

## ⭐ Features

### 🔍 Search Your Constituency
- Find your constituency quickly by name.
- View essential information at a glance.

### 🗺️ Constituency Overview
For each constituency, you can explore:
- Demographic information  
- Past three election results  
- List of upcoming candidates  
- Quick comparisons and trend insights

### 🧭 Browse All Constituencies
- See all constituencies in a single view  
- Filter or search by candidate or constituency  
- Smooth, responsive interface for fast exploration

---

## 🎯 Purpose

This project aims to make election-related data **transparent, accessible, and easy to understand** for the public.  
By gathering information from publicly available sources and presenting it cleanly, HelloYB.my helps voters better familiarize themselves with their constituencies and candidates.

This is **not** a political advocacy tool — it simply organizes information so users can explore and verify details for themselves.
